This branch, under the `kakrs/` directory, contains a vibe coded port of the
Kakoune text editor from C++ to Rust.

100% of the code was generated by Claude Opus 5.5, 0% of it was reviewed by a
human being. It took about 4 hours, for an estimated cost of about $160 (if I
was using the API, but I'm using a subscription). My initial prompt was:

> You are in the kakoune c++ codebase. I have created a directory called
> `kakrs`, where I have run `cargo init`.
> /goal port kakoune to rust

And then like 30 minutes in I said something like "please strongly consider
using [Hegel](https://docs.rs/hegeltest) to write property tests" and gave it
the [Hegel skill](https://github.com/hegeldev/hegel-skill). But otherwise I was
basically hands off.

It's incredible that this is possible. These tools are unimaginably powerful.
But I feel nothing. This means nothing.

I'm happier crafting [my own text editor](https://github.com/evanrelf/indigo),
and understanding ~every line of code.
